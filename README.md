# App Android - Pedidos Rápidos

Proyecto desarrollado para un cliente real (emprendedora de un negocio de comidas y postres). Aplicación móvil para la gestión de pedidos y productos.

## Mi rol en el proyecto
- Desarrollo del CRUD de pedidos (registro, edición y eliminación).
- Gestión de productos: alta de nuevos productos, edición, eliminación y actualización de precios.
- Creación del backend con API REST y gestor de menú dinámico.
- Conexión de la app Android con la API usando Retrofit y Volley.

## Tecnologías utilizadas
- Java, Android Studio, SQL ...
